Лабораторна робота № 8

Тема
Робота з форматами XML та JSON у PHP.

Мета роботи
Навчитися створювати, читати, перевіряти та змінювати XML- і JSON-документи за допомогою PHP.

Структура проєкту
- `common.php` — спільні функції для роботи з даними.
- `read_persons_xml.php` — читання даних із XML.
- `read_persons_json.php` — читання даних із JSON.
- `dom_traversal.php` — обхід XML-документа за допомогою DOM.
- `write_persons_xml.php` — створення XML-файла.
- `write_persons_json.php` — створення JSON-файла.
- `persons.xml`, `persons.json` — тестові дані.
- `xml/` — версія каталогу книг із використанням XML.
- `json/` — версія каталогу книг із використанням JSON.

Вимоги
- Встановлений XAMPP.
- Запущений модуль Apache.
- У PHP увімкнені необхідні розширення DOM і mbstring.

Інструкція запуску
1. Скопіювати папку лабораторної роботи до `C:\xampp\htdocs\lab-08\src\`.
2. Запустити Apache у панелі керування XAMPP.
3. Відкрити потрібну сторінку в браузері.

XML-версія каталогу:
`http://localhost/lab-08/src/xml/`

JSON-версія каталогу:
`http://localhost/lab-08/src/json/`

Для запуску PHP-скриптів створення файлів можна скористатися командним рядком у папці з відповідними скриптами.
У роботі використовуються вигадані імена та тестові записи. Реальні персональні дані не використовуються.
